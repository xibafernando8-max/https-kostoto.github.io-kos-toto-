# KOSTOTO — Data Parser

Versi tampilan neon biru/merah dengan wallpaper anime.

## Jalankan lokal
Buka `index.html` di browser. Untuk fungsi spreadsheet, koneksi internet dibutuhkan untuk memuat library XLSX.

## Terbitkan di GitHub Pages
Unggah seluruh isi folder ini ke direktori root repositori (bukan ZIP-nya saja), lalu aktifkan Settings → Pages → Deploy from a branch → `main` → `/(root)`.
